# ToDo List App 📝

A simple iOS task management app written in SwiftUI.

## Features
- Adding new tasks
- Marking tasks as completed
- Deleting individual tasks
- Clearing the entire list

## Technologies
- Swift 5
- SwiftUI
- Xcode 16

## What I learned
- Working with @State and @FocusState
- List, ForEach, NavigationView
- Animations with withAnimation
- Structures with Identifiable and UUID
